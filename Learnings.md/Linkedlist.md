# Linked List

- Linked List is a linear data structure.
- Elements are called nodes.
- Each node contains data and a reference (address) to the next node.
- Head points to the first node.
- Last node points to null.
- Nodes are not stored in continuous memory locations.
- Dynamic in size.

## Types
- Singly Linked List
- Doubly Linked List
- Circular Linked List

## Operations
- Insert at beginning.
- Insert at end.
- Insert at specific position.
- Delete at beginning.
- Delete at end.
- Delete at specific position.
- Search an element.
- Display all elements.

## Important Points
- Insertion at beginning: O(1).
- Deletion at beginning: O(1).
- Searching: O(n).
- Accessing an element by index: O(n).
- No direct index-based access like arrays.
- Memory is allocated dynamically.
